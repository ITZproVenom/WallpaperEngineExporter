# LumaForge

A focused iOS Wallpaper Engine exporter.

## Workflow

1. Copy a wallpaper download link.
2. Paste it into LumaForge.
3. Tap **Download Wallpaper**.
4. Tap **Export as MP4**.
5. Share the resulting MP4.

LumaForge also accepts wallpaper files imported through the iOS Files picker.

### Important

The downloader expects a URL that actually serves the wallpaper file. A normal Steam Workshop HTML page is not itself a downloadable wallpaper package. Steam Workshop content can require Steam's content-delivery system rather than a single public file URL.

The app does not require a Steam login for this workflow.

## Build

Xcode 26, iOS 18+, unsigned IPA in CI.
